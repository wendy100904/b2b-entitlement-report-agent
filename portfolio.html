平台各产品用户特征分析User Segmentation & Product Affinity Analysis

数据分析 · 独立项目Data Analytics · Solo Project
Python / PySpark / scikit-learn

基于招聘平台付费企业用户的多产品使用数据，构建「取数 → 特征工程 → 聚类分群 → 打标签 → 关联分析 → 路径挖掘」完整分析流程，产出可直接指导运营的用户分层结果。Built an end-to-end analytics pipeline — extraction → feature engineering → K-Means segmentation → labeling → association mining → path mining — on multi-product usage data of paying enterprise users, producing operationally actionable segmentation.

  • 分群与交叉推荐：RFM + 使用强度 + 产品多样性 + 活跃度评分聚合特征；K-Means + 肘部法则（二阶差分）自动定 K，PCA 降维验证；支持度 / 置信度 / 提升度挖掘可交叉推荐的产品组合Segmentation & cross-sell: aggregated RFM + usage intensity + product diversity + activity scores; K-Means with elbow method (2nd-order difference) auto-selects K, PCA validates clusters; support/confidence/lift mined for cross-sell product pairs
  • 路径与画像：时序子串频次统计提取长度 ≥ 3 的高频行为路径；构建「聚类标签 + 属性 / 城市 / 行业 / 薪资 / 活跃度」复合标签体系，输出分群画像与业务概览看板Paths & profiles: frequent behavioral paths (length ≥ 3) via time-series substring frequency; composite tagging (cluster + attributes/city/industry/salary/activity) feeding segment profiles and an executive overview dashboard
  • 生产规范：PySpark 对接生产 Hive 取数；涉密数据代号化、占比化，附带可复现测试数据Production practice: PySpark reads from production Hive; sensitive data anonymized and ratio-based, with reproducible test data
